# Estabilização do Ambiente Ubuntu — FCC e VS Code

## Objetivo
Estabilizar o Free Claude Code (FCC), corrigir falhas de conexão,
simplificar a arquitetura e consolidar o ambiente de desenvolvimento.

## Regras de trabalho
- Registrar todas as alterações em Markdown.
- Registrar os comandos executados e seus resultados.
- Fazer backup antes de alterações de configuração.
- Validar cada mudança antes de avançar.
- Manter procedimentos de rollback.
- Não registrar senhas, tokens, chaves ou outros segredos.
- Não remover componentes antigos sem validação e autorização.

## Escopo
- Free Claude Code
- FCC nativo e componentes auxiliares
- Docker
- VS Code / code-server
- systemd
- Caddy e OAuth2 Proxy (preservar autenticação)
- Ollama (preservar configuração até necessidade comprovada)
